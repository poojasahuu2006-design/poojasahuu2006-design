## ⭐ Featured Flagship Project

### 🤖 [WhatsApp AI Buddy — Autonomous CRM & Automation SaaS](https://github.com/poojasahuu2006-design/whatsapp-buddy-web)
*A production-grade Autonomous WhatsApp AI Agent & Cloud CRM SaaS that connects live WhatsApp numbers to intelligent AI agents, Google Calendar appointment scheduling, and persistent MongoDB Atlas cloud storage.*

* **Key Highlights:**
  - **Sub-Second AI Auto-Replies:** Real-time intent classification for pricing, services, and queries strictly enforcing professional single-sentence constraints.
  - **Google Calendar Auto-Booking:** Autonomous slot detection (e.g. *"tomorrow at 4 PM"*) with Google Calendar API integration and 1-click confirmation links.
  - **Embedded Baileys Gateway:** Direct multi-device WhatsApp WebSocket integration supporting live QR code linking and session persistence on MongoDB Atlas.
  - **Real-Time Dynamic CRM:** Synced inbox, direct contact management, and live activity metrics.
  - **Anti-Spam & Deduplication:** In-memory caching and message filtering preventing duplicate webhook triggers and group loops.
* **Tech Stack:** `React 18`, `Vite`, `Node.js`, `Express`, `MongoDB Atlas`, `Baileys WebSocket`, `Google Calendar API`, `TailwindCSS`
* **Links:** [📂 GitHub Repository](https://github.com/poojasahuu2006-design/whatsapp-buddy-web) · [🌐 Live Deployed SaaS](https://whatsapp-buddy.onrender.com)
